## 3. Diagnostic patterns

- **Affective vs functional.** Functional whys recovered 30.0 / 54.0 weighted points (55.6%), while affective whys recovered 44.0 / 92.0 (47.8%). Sync, simulation, and telemetry architecture were more robust than relational/social/product-tone exceptions.
- **Weight-3 vs weight-2.** Weight-3 whys recovered 62.0 / 104.0 (59.6%), much better than weight-2 whys at 12.0 / 42.0 (28.6%). High-weight architecture and accessibility rationales survived better than small exception whys.
- **System-level vs feature-level.** The planner preserved philosophy more reliably than the reconstruction preserved feature-level rationale: S-level 71.4% vs F-level 45.8%.
- **Multi-layer recovery.** The most common loss was the downstream consequence layer: F3, F7, F14, F18, F27, F30, and F40 all retained implementation logic while dropping product-collapse or relationship-shift consequences.
- **Subdomain patterns.** Server state, sync, privacy boundaries, accessibility, and procedural audio scored well. Return/settle details, social restraint, export/deletion, and identity-continuity rationale were weaker.
- **Evidence-bound effects.** Seventeen included whys were rule-without-why cases; v06 denied credit for mechanisms like hidden trait numbers, matter-of-fact sync errors, account export/deletion, per-invite sharing, and visit logs when rationale did not survive.

## 4. Recommendations for v2 hardening

- Keep the targeted F29-F40 headroom set. It was useful here because the plan implemented many features while dropping why-level recovery.
- Add more small interaction exceptions like no-return-toast, greeting variation, and close-tab equivalence; these separated high-level scope capture from exact product intent.
- For system-level affective whys, require a note distinguishing explicit reconstruction from plan-only cross-cutting evidence, especially for specificity and restraint.
- Preserve evidence-bound scoring. It prevented mechanism-only text from earning rationale credit and gave a clear failure signature.

## 5. Methodology caveats

- **Fresh-context fidelity.** The frozen reconstruction was read-only and treated as plan-derived. No PRD, peer slot, or other wave was read. Validity audit verdict: PASS.
- **Single-run-at-temperature limitation.** This is one run; no variance signal is available from this score alone.
- **Borderline capture calls.** I leaned inclusive on presence-definition/presence-accounting and some compressed layout/social features. The main excluded feature-why anchors were F10 and F11.
- **System-level cross-cutting.** The strict three-feature bar was straightforward for S5, S7, S8, and S9, but more subjective for S2-S4.
- **Confabulation cases.** I found no material ungrounded reconstruction cases; the main issue was omission/rule-only recovery, not invented rationale.
- **Evidence-bound denials.** Many plausible v1-style recoveries were denied because the reconstruction only preserved the operational rule.
