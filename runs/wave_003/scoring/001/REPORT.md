## 3. Diagnostic patterns

- Affective vs functional: functional whys recovered 38.0 / 54.0 weighted points, while affective whys recovered 58.0 / 98.0. The server-authority, privacy, telemetry, and performance architecture survived better than the relationship-shaping affective rationales.

- Weight-3 vs weight-2: weight-3 whys recovered 70.0 / 108.0, while weight-2 whys recovered 26.0 / 44.0. High-weight whys did a little better, but often as partials: the primary rule survived and the secondary/downstream layer disappeared.

- System vs feature: system fidelity, 78.6%, is materially higher than feature fidelity, 59.7%. The PLAN carried philosophy well, but B compressed many feature-level exception whys into operational rules.

- Multi-layer pattern: L1s were usually recovered, L2/L3s were more fragile. F2, F10, F15, F27, and F35 show this pattern clearly.

- Subdomain pattern: accounts/sync and telemetry were strongest; onboarding/social/notebook whys were weaker. F29, F33, and F39 were captured but lost the rationale that prevents them from becoming different product surfaces.

- Evidence-bound effects: eight rows were rule-without-why. Six rows had PLAN-grounded layers that B did not reconstruct; no ungrounded reconstruction cases were counted.


## 4. Recommendations for v2 hardening

- Keep evidence-bound scoring. This run would look deceptively excellent under feature capture alone.

- Add more targeted affective exception whys in social, notebook, and onboarding areas, where rules survived but motives did not.

- Track missing layers separately for multi-layer whys. Partial recovery often means the primary cause survived while secondary contributor or downstream consequence did not.

- Preserve the cross-cutting system bar but separately record whether B elevated the principle in system intent or only named related per-feature rules.


## 5. Methodology caveats

- Fresh-context fidelity: the reconstruction appears plan-derived. The validity audit found no gold ID leakage or 1:1 gold mapping.

- Single-run limitation: this is one model/sample configuration. No variance signal is available inside this slot.

- Borderline capture: feature 52 was counted captured because PLAN uses any pointer/key in the scene during the five-second settle undo window, a semantic equivalent of click-anywhere-to-undo. This did not materially affect planning quality.

- System-level cross-cutting: S2, S4, and S6 were the most subjective calls. The PLAN was cross-cutting, but B compressed or failed to elevate one or more layers.

- Confabulation: no rows were penalized for ungrounded reconstruction.

- Evidence-bound denials: v06 denied full credit where reconstruction evidence did not carry all layers, even when PLAN grounding was present.

- Rule-without-why: the main mechanism-only misses were F5, F6, F11, F19, F23, F29, F33, and F39.
