## 3. Diagnostic patterns

- **Affective vs functional.** The split was close: functional recovered 42.0 / 54.0 weighted points (77.8%), affective recovered 78.0 / 98.0 (79.6%). Functional misses centered on calibration/privacy layers (F1, F13, F16, F20), while affective misses centered on relationship-specific reasons for rules (F6, F29, F39).
- **Weight-3 vs weight-2.** Weight-3 whys recovered 82.0 / 108.0 (75.9%), below weight-2 whys at 38.0 / 44.0 (86.4%). The heavy whys survived as primary rules, but secondary/downstream layers were often compressed.
- **System-level vs feature-level.** System-level fidelity was higher (85.7%) than feature-level fidelity (77.4%). The plan/reconstruction preserved the philosophy strongly, but a few feature-specific exceptions lost their exact rationale.
- **Multi-layer recovery patterns.** The most commonly dropped layer was downstream consequence: S1, F1, F4, F13, F16, F30, and F35 all retained the mechanism but compressed the failure mode.
- **Subdomain patterns.** Accessibility, sync, and core drift performed well. Onboarding/social nuances leaked more: F29 and F39 were not recovered, and F37/F38 survived mostly as control/notification rules.
- **Evidence-bound effects.** The stricter operator mainly denied credit for rule-only survival. F6, F29, and F39 would look better under loose semantic scoring, but v06 keeps them at none because the canonical why is missing or explicitly unrecoverable.

The failure shape suggests the plan is excellent as an implementation artifact, but the reconstruction compresses some affective exception rationales into build rules.

## 4. Recommendations for v2 hardening

- Keep targeted headroom whys like F29-F40. They revealed real discrimination even in a near-complete plan.
- Consider splitting dense single-layer whys such as F6 and F39 into multi-layer whys, because both had partial residue but no legal partial credit.
- Preserve v06 evidence-bound scoring. It prevented mechanism-only rows from becoming false-positive why recovery.
- Add a small aggregate for missing multi-layer downstream consequences; that would make the most common compression failure easier to compare across runs.
- Keep the current functional/affective mix. This run missed both types at similar rates, which suggests the mix is usefully balanced.

## 5. Methodology caveats

- **Fresh-context fidelity.** This scoring pass used only the allowed phase_two package, assigned plan/metadata/timing entry, frozen reconstruction, and scoring slot. No PRD, peers, other waves, subagents, or background agents were used.
- **Single-run-at-temperature limitation.** This is one plan and one reconstruction, so it has no variance signal by itself.
- **Borderline capture calls.** Only feature #7 was borderline: the plan does not create a literal glossary, but it operationally defines the terms. Counting it captured changes planning from 99.2% to 100.0% but does not affect fidelity.
- **System-level cross-cutting.** The (b) bar was straightforward for all S rows; each had at least three visible plan inheritances. S1 and S2 partials come from compressed layers, not lack of cross-cutting plan evidence.
- **Confabulation cases.** No clear ungrounded reconstruction rationale was found. Some rows were compressed or rule-only, but still plan-derived.
- **Evidence-bound denials.** F6, F29, and F39 were denied because the reconstruction lacked sufficient gold-why rationale; F29 also invoked `NOT RECOVERABLE FROM PLAN`.
- **Rule-without-why cases.** The three cases were F6, F29, and F39.
- **Timing compromise.** TIMING.json contained phase 1 and phase 2A fields only. I included those bounded fields in the score JSON and did not write TIMING.json.
