## 3. Diagnostic patterns

- **Planning capture saturated.** The PLAN addressed all 120 features. The only inclusive capture call was #7, the glossary row, because domain terms are defined throughout the plan rather than in a standalone glossary.
- **Feature-level whys leaked more than system intent.** System fidelity was 89.3%, while feature fidelity was 71.0%. The reconstruction kept architecture, privacy, accessibility, and announcement restraint; it dropped several small product-rationale exceptions.
- **Weight-3 whys survived better than weight-2.** Weight-3 rows recovered 84.0 / 108.0 (77.8%), compared with weight-2 rows at 29.0 / 44.0 (65.9%). The most load-bearing mechanisms were usually easier to infer from the plan.
- **The common multi-layer miss was downstream consequence.** Rows such as F9, F16, F18, F27, F30, F31, and F35 recovered the primary rule but not the deeper failure story.
- **Rule-without-why cases are concentrated in social/product-restraint exceptions.** F5, F6, F11, F23, F29, F37, and F39 preserved mechanisms but not the gold rationale.
- **No ungrounded reconstruction was scored.** When the reconstruction was thin, it tended to say little or mark not recoverable rather than invent a rationale.

What this suggests: the candidate planner encoded the buildable product almost completely, but phase-2A reconstruction compressed some rationale into implementation rules. The benchmark is doing useful work at the rationale layer rather than the feature inventory layer.

## 4. Recommendations for v2 hardening

- Keep targeted headroom additions like F29-F40. They are valuable because this run captured the features but missed several of their deeper whys.
- Preserve evidence-bound scoring. It prevented PLAN-only rationale from inflating reconstruction fidelity.
- Add a rubric note for system principles recovered outside the `## System-level intent` section. S6 was recoverable in per-feature text but weaker in the system section, which made the call subjective.
- Consider allowing explicit half-credit for single-layer affective whys in a future rubric variant, or keep all-or-none but add more examples. F6, F21, F34, and F37 show how poetic rationales can be partly but not completely reconstructed.
- Keep the system cross-cutting bar at three inherited decisions, but require scorers to list the evidence as this report does; it made S4 and S6 transparent.

## 5. Methodology caveats

- **Fresh-context fidelity.** Scoring used only the frozen reconstruction, plan, rubric, gold list, schema, constants, and assigned timing entry. I did not modify `RECONSTRUCTION.md` or consult `prd/`.
- **Single-run limitation.** This is one temperature/run sample; no variance signal is available inside slot 001.
- **Borderline capture calls.** Feature #7 was counted as captured under the inclusive capture convention because the plan defines domain concepts across implementation sections.
- **System-level cross-cutting.** S4 and S6 were the main subjective calls. S4 had plan inheritance but no clear system-level reconstruction evidence. S6 had detailed per-feature reconstruction evidence but thinner system-level principle articulation.
- **Confabulation cases.** None were scored; `ungrounded_reconstruction_count` is 0.
- **Evidence-bound denials.** Thirteen included whys had plan-grounded rationale layers that the reconstruction did not fully recover.
- **Rule-without-why cases.** Seven included whys preserved mechanisms without the gold rationale: F5, F6, F11, F23, F29, F37, and F39.
