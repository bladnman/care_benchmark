## 3. Diagnostic patterns

- **Affective vs functional.** Recovery was similar by type: functional whys recovered 40/54 weight (74.1%), while affective whys recovered 75/98 (76.5%). The leak was not simply emotional prose; functional details like F1, F13, and F16 also lost layers.
- **Weight-3 vs weight-2.** Weight-3 whys recovered 80/108 (74.1%), below weight-2 whys at 35/44 (79.5%). Multi-layer whys exposed compression: B often kept the primary rule but dropped the secondary failure mode.
- **System-level vs feature-level.** System-level fidelity was high at 27/28. Feature-level fidelity was lower at 88/124. The plan carried philosophy strongly, but reconstruction compressed feature-specific motives.
- **Multi-layer recovery.** The most commonly dropped layer was the secondary contributor or downstream consequence: examples include F4 chorus artifacts, F10 well-meaning toast temptation, F12 notebook voice concentration, F30 relationship-deepening, and F40 visual-rhythm cadence.
- **Subdomain patterns.** Accessibility did well (F24-F26 full, F40 partial). Privacy/telemetry was mixed: F20 and F36 full, but F34 export rationale was absent. Social mechanics were mostly strong, with F39 losing the no-show-off-mode rationale.
- **Evidence-bound effects.** F6, F14, F19, F34, and F39 are the clearest rule-without-why cases. F6 also shows a plan-only loss: the plan grounded call recognizability, but B reconstructed only performance/comprehensibility.

The failure shape suggests a strong planner and a generally honest reconstructor: broad product intent survived, but feature-level explanatory headroom still discriminates because secondary motivations are easy to compress away.

## 4. Recommendations for v2 hardening

- Keep targeted feature-level headroom. Rows like F6, F34, and F39 separated rule capture from rationale capture in a useful way.
- Retain multi-layer scoring for high-weight whys. It exposed a consistent primary-rule-only compression pattern that a single-layer rubric would hide.
- Consider adding more exception whys around quiet account/settings features. Export, deletion, telemetry, and visit-log surfaces are easy for plans to implement mechanically while losing why.
- Keep the system-level cross-cutting appendix. S4 was a useful fine call: restraint clearly shaped the plan, but the reconstruction did not identify it as a principle.
- For future prompt variants, make explicit that a reconstruction should not infer deeper rationale from a correct rule. This run had no contamination, but the evidence gate denied several plausible v1-style recoveries.

## 5. Methodology caveats

- **Fresh-context fidelity.** This scoring pass used only the allowed phase-two files, run 001 plan/metadata/timing entry, frozen reconstruction, and scoring output slot. No PRD, peer slots, or other waves were read.
- **Single-run limitation.** This is one run with no variance signal.
- **Borderline capture calls.** Feature 7 (glossary) and feature 23 (species pool size) were leaned inclusive. Feature 62 (parallax) and feature 68 (empty-aviary state) were not captured. The borderline inclusions do not affect reachable F1-F40 why anchors.
- **System-level cross-cutting.** S4 is the main subjective call: PLAN preserves restraint across at least three decisions, but B did not identify the principle, so it scored partial.
- **Confabulation cases.** No ungrounded gold-rationale assertions were counted. Some non-gold rationale appeared for F6, but it was grounded in the plan and simply did not recover the gold why.
- **Evidence-bound denials.** F6, F14, F19, F34, and F39 were denied because the frozen reconstruction lacked the gold rationale even though the feature rule survived.
- **Rule-without-why cases.** Six included whys were marked rule-without-why: S4 plus F6, F14, F19, F34, and F39.
