## 3. Diagnostic patterns

- **Affective vs functional.** Rates are close: affective 72.0/98.0 and functional 40.0/54.0. The leak is not purely affective; strict functional layers such as F1/F13 silent corruption and F2 failure-band calibration also compressed away.
- **Weight-3 vs weight-2.** Weight-3 whys recover worse (76.0/108.0) than weight-2 whys (36.0/44.0) because the reconstruction usually keeps primary mechanism while losing secondary/downstream layers.
- **System vs feature.** System-level fidelity is strong (24.0/28.0); feature-level fidelity is materially lower (88.0/124.0). The plan carries philosophy well, but reconstruction often turns feature whys into implementation summaries.
- **Multi-layer pattern.** Missing layers are usually L2/L3: S2 processed-vs-seen, S6 settle/tab-close equivalence, F2 Tamagotchi-vs-screensaver band, F30 economy erosion, and F40 visual-rhythm equivalence.
- **Subdomain pattern.** Accounts/sync, procedural audio, and accessibility are strongest. Return-greeting details and small interaction exceptions are weakest: absence length, boldness greeting, greeting stagger, offer reaction variation, and offer cooldown are not captured in the plan.
- **Evidence-bound effects.** F8 is the cleanest evidence-bound denial: the plan says numeric exposure would make traits numbers to optimize, but reconstruction only preserved no-stat-panel mechanics. F5, F9, F11, and F23 are similar mechanism-without-why cases.

The failure shape suggests a planner that produced an unusually robust architecture while compressing some small, emotionally precise interaction rationales into general product principles.

## 4. Recommendations for v2 hardening

- Keep targeted feature-level exception whys. They created headroom: F8, F11, F23, F30, and F31 exposed differences between building the rule and carrying the reason.
- Add a few more gold whys around arrival/greeting micro-behavior. This run captured return-greeting as a feature but missed absence-length, boldness-ordering, and stagger, which changed the true product feel.
- Preserve the multi-layer scoring design, but make the layer ledger first-class in any future validator. Most informative calls here were partial, not binary.
- For system-level S2/S6-style principles, distinguish named-principle inheritance from full emotional/relationship rationale. The plan named the principles and enforced them, but some gold layers still did not travel.
- Keep score JSON aggregate-only. The report twins carry the evidence; loose score JSON did not need any per-feature leak to explain the result.

## 5. Methodology caveats

- **Fresh-context fidelity.** Artifact evidence supports fresh-context isolation: reconstruction contains no gold IDs and follows PLAN sectioning, not the gold S/F order. The validity audit verdict is PASS.
- **Single-run-at-temperature limitation.** This is one run; no variance signal is available from this slot alone.
- **Borderline capture calls.** I leaned inclusive on #44 settle opt-in and #55 bird-chosen perch. #44 only affects F11 reachability, but F11 scored none for why recovery, so the inclusive call did not inflate numerator.
- **System-level cross-cutting.** S2 and S6 were the subjective system calls. Both are cross-cutting in PLAN but only partial at the layer level.
- **Confabulation cases.** No ungrounded reconstruction cases were counted. Where reconstruction asserted rationale, it was grounded in PLAN; the main issue was omission/compression.
- **Evidence-bound denials.** F8 is plan-only-not-reconstructed; F5, F9, F11, and F23 are mechanism-only recoveries. These would likely score higher under a looser v1-style semantic read.
- **Operational timing.** `TIMING.json` had phase1 and phase2a data for run 001 only; phase2b timing was not present at write time, so the score JSON includes only available bounded timing fields.
