## 3. Diagnostic patterns

- **Affective vs functional.** Functional and affective recovery were nearly tied: functional 42.0/54.0, affective 77.0/98.0. The leakage was more about depth than domain type.
- **Weight-3 vs weight-2.** Weight-3 whys recovered 82.0/108.0 while weight-2 whys recovered 37.0/44.0. High-weight rows exposed dropped secondary/downstream layers, especially F1, F2, F13, F14, F30, F31, and F35.
- **System-level vs feature-level.** System-level fidelity was high at 25.0/28.0. Feature-level fidelity dropped to 94.0/124.0 because the reconstruction often preserved rules while compressing affective rationale.
- **Multi-layer pattern.** Primary causes usually survived. Secondary affective explanations and downstream failure modes were the most common losses.
- **Subdomain pattern.** Accounts/sync, privacy, and accessibility were especially strong. Social surface whys were more brittle: F23 and F39 preserved the product rule without the relationship rationale.
- **Evidence-bound effects.** v06 denied credit for F40 because the reconstruction explicitly wrote NOT RECOVERABLE FROM PLAN, and denied F5/F23/F39 because the evidence was mechanism-only.

## 4. Recommendations for v2 hardening

- Add more targeted feature exceptions around social/privacy surfaces. F23 and F39 show a plan can implement the rule while losing the relationship-shaped why.
- Keep multi-layer feature whys. The secondary/downstream layers created useful headroom on otherwise excellent plans.
- Add a rubric calibration example for broad system words such as "restraint". S4 was preserved by the plan but only partially reconstructed because the word was attached to anti-gamification more than depth-over-variety.
- Keep evidence-bound scoring. It cleanly separated complete implementation planning from successful intent reconstruction.

## 5. Methodology caveats

- **Fresh-context fidelity.** Same-context safeguard appears to hold. The reconstruction contains no gold IDs, no rubric vocabulary, and mirrors plan headings rather than gold headings.
- **Single-run limitation.** This is one run with no variance signal.
- **Borderline capture calls.** Inclusive calls: feature 41 (curiosity implied only by personality), feature 68 (empty state narrower than PRD wording), feature 90 (visits default-off implicit in explicit invite model). These do not affect the 40 feature-why denominator.
- **System-level cross-cutting.** S4 is the main subjective call: plan preserved the principle, reconstruction under-identified it.
- **Confabulation cases.** None counted. The reconstruction reads as plan-derived and often honestly marks non-recoverable details.
- **Evidence-bound denials.** F5, F23, F39, and F40 are rule-without-why or explicit non-recovery cases.
- **Operational compromise.** `TIMING.json` had phase 1 and phase 2A only for this slot; no phase 2B timing was available inside the scorer context, so the score JSON includes only available bounded phase timing.
