## 3. Diagnostic patterns

- **Affective vs functional.** Functional whys recovered better (29.0/50.0 = 58.0%) than affective whys (39.0/78.0 = 50.0%). Architecture-forced rationales survived: S7, F17, and F18 were full. Affective social exceptions such as F23, F37, F38, and F39 often became rules without relationship-protection rationales.
- **Weight-3 vs weight-2.** High-weight whys recovered at 52.0/92.0 = 56.5%; weight-2 whys recovered at 16.0/36.0 = 44.4%. The high-weight material did survive better, but mostly as partial recoveries.
- **System-level vs feature-level.** The planner preserved broad philosophy somewhat better than feature-specific why: system 57.1%, feature 52.0%. The gap is small because many system principles were also compressed.
- **Multi-layer recovery patterns.** Primary causes survived most often. Secondary contributors survived for technical whys like F1/F13 and sync whys like F17/F18. Downstream consequences were often dropped: F4 lost audio-spine cascade, F27 lost foothold/slippery-slope, and S2 lost the processed-vs-seen consequence.
- **Subdomain patterns.** Sync and server state were strongest. Accessibility was middle: the same-surface design survived, but launch/parity consequences were thinner. Social/privacy was weakest because the plan listed exclusions and invite mechanics while dropping the private-relationship rationale.
- **Evidence-bound effects.** The operator denied nine rule-only included whys and two plan-only system whys. Without evidence binding, several of F6, F23, F26, F34, F37, F38, and F39 might look superficially preserved because the operational rule appears.

The failure shape suggests the candidate is a capable implementation planner but compresses product philosophy into operational constraints. It can build much of the product, but many affective exception rationales do not survive the plan-to-reconstruction channel.

## 5. Methodology caveats

- **Fresh-context fidelity.** This scoring pass treated the frozen reconstruction as read-only and did not modify it. The prompt explicitly supplied fresh-context conditions; I saw no same-context artifact inside the reconstruction.
- **Single-run limitation.** This is one run, so there is no variance signal for the candidate model or prompt.
- **Borderline capture calls.** I leaned inclusive on several calls: S2 principle feature, mood persistence, bird-chosen perch, snapshot-on-visibility, visit log, and reduced-motion charm. These choices raised planning quality but did not automatically raise fidelity.
- **System-level cross-cutting.** S3 and S4 were the most subjective: the plan had cross-cutting evidence, but B did not identify the principle, so both were partial plan-only recoveries.
- **Confabulation cases.** I did not count any positive recovery from ungrounded reconstruction claims. Some reconstructed rationales were merely generic, but they were grounded in the plan text.
- **Evidence-bound denials.** F6, F23, F26, F32, F34, F35, F37, F38, and F39 are rule-without-why cases. F34 and F35 were explicitly marked `NOT RECOVERABLE FROM PLAN` and scored none.
- **Operational timing.** TIMING.json contained phase1 and phase2a fields for run 001. Phase2b timing was not yet present, so the strict score JSON includes only available timing fields.
