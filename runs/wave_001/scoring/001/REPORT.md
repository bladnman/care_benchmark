## 3. Diagnostic patterns

- **Affective vs functional.** Functional whys recovered at 59.3%, while affective whys recovered at 55.4%. Server ownership, telemetry boundaries, and no-LWW logic were stronger than relationship-shaped product decisions.
- **Weight-3 vs weight-2.** Weight-3 rows recovered at 63.5%; weight-2 rows recovered at 40.5%. Multi-layer rows often kept primary mechanisms but lost downstream consequences.
- **System vs feature level.** System fidelity (82.1%) outpaced feature fidelity (50.8%). The plan encoded architecture and principles better than feature-specific whys.
- **Multi-layer pattern.** Layer 1 survived most often; layer 2 and especially layer 3 leaked for presence, no-streaks, return greeting, bird identity, age-based unlocks, and narration cadence.
- **Subdomains.** Accounts/sync, telemetry, accessibility, and performance were strongest. Social/visit affect, starter/adoption affect, greeting specifics, and notebook authorship were weakest.
- **Evidence-bound effect.** Mechanism-only rows such as F5, F6, F8, F19, F22, F23, F31, F33, F37, F38, and F39 were denied recovery because the frozen reconstruction did not state the gold rationale.

## 4. Recommendations for v2 hardening

- Keep targeted headroom additions for affective exceptions; they revealed rule-without-why failures that the original canonical set might have hidden.
- Preserve multi-layer whys for high-weight rows. Partial scoring was useful for separating mechanism capture from downstream consequence recovery.
- Add a first-class "mechanism-only" dashboard grouping so v06 rule-without-why cases can be compared across models.
- Clarify borderline capture conventions for small UI exclusions and gesture details, especially when a plan names a broader feature but omits the exact refusal.

## 5. Methodology caveats

- **Fresh-context fidelity.** The frozen reconstruction is plan-structured and lacks gold IDs; no contamination signs were found in the audit.
- **Single-run limitation.** This is one run at one candidate/evaluator configuration; it has no variance signal.
- **Borderline capture calls.** Features 52, 57, and 93 were counted captured inclusively. Marking them missed would lower planning quality but not alter the main fidelity finding.
- **System-level cross-cutting.** S2 and S6 were partial because the reconstruction and plan did not carry all required layers despite broad cross-cutting evidence.
- **Confabulation cases.** None counted. The reconstruction stayed grounded in the plan; failures were mostly omission/compression.
- **Evidence-bound denials.** Several plausible rule-level recoveries were scored none because exact why evidence was absent.
- **Rule-without-why cases.** Fifteen included feature whys preserved a mechanism but not the gold rationale.
- **Operational timing.** Assigned timing contained phase 1 and phase 2A only; no phase 2B timing was available at write time.
