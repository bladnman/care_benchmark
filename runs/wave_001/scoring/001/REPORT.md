## 3. Diagnostic patterns

- **Affective vs functional.** Functional recovery was stronger: 44/54 recovered weight versus 69/98 for affective whys. Functional architecture such as S7, F17, F18, F20, and F36 survived very well.
- **Weight-3 vs weight-2.** Weight-3 whys recovered slightly better by weight (82/108) than weight-2 whys (31/44), but many high-weight rows lost one layer rather than failing outright.
- **System-level vs feature-level.** System fidelity was high at 25/28; feature fidelity dropped to 88/124 because several mechanisms were reconstructed without their deeper product rationale.
- **Multi-layer recovery.** Primary mechanisms usually survived. Secondary contributor and downstream consequence layers leaked most often, especially in F9, F13, F16, F30, F31, F35, and F40.
- **Subdomain patterns.** Server-side simulation, sync, privacy, and accessibility were strongest. The weakest pockets were subtle affective exceptions: opt-in settle, error tone, starter-arrival framing, performance-as-affect, and no show-off rendering.
- **Evidence-bound effects.** Six rows were rule-without-why cases: F5, F11, F19, F26, F29, and F39. S4 was plan-only at the system level: the plan preserved restraint, but the reconstruction did not name it as a system principle.

The failure shape suggests the candidate plan is excellent as a build artifact and good as an intent carrier, but it still converts some relational/affective rationales into implementation prohibitions.

## 5. Methodology caveats

- **Fresh-context fidelity.** The scorer was given a fresh-context phase-2B prompt and a frozen reconstruction. I did not modify the reconstruction.
- **Single-run limitation.** This is one candidate run, with no variance estimate.
- **Borderline capture calls.** I counted the glossary/domain-terms feature and visits-default-off feature as captured semantically. Privacy policy link was the only missed feature.
- **System-level cross-cutting.** S4 was the subjective edge: the plan preserved restraint across several design decisions, but reconstruction did not identify the principle, so it received partial credit.
- **Confabulation cases.** I did not identify ungrounded reconstruction claims that affected recovery credit.
- **Evidence-bound denials.** F5, F11, F19, F26, F29, and F39 were denied despite clear feature capture because the frozen reconstruction did not carry the gold why.
- **Operational timing.** TIMING.json had phase1 and phase2a data for run 001 but no phase2b timing at score-write time; the score JSON includes only available timing fields.
