## 3. Diagnostic patterns

- **Affective vs functional.** Affective whys recovered slightly better (76/98, 77.6%) than functional whys (38/54, 70.4%). The functional misses were mostly precision rationales: F1/F13 did not recover why looser presence definitions silently corrupt population drift, and F16 dropped the impossible-to-retrofit consequence of email-derived identifiers.
- **Weight-3 vs weight-2.** High-weight whys were not weaker overall (82/108, 75.9%), but many were partial rather than full. The reconstruction carried primary mechanisms well and most often dropped secondary contributor or downstream consequence layers, especially S2, S6, F4, F10, F14, F27, F30, and F40.
- **System-level vs feature-level.** The plan preserved philosophy very well, but the reconstruction's system section did not always name all philosophy families. S3 and S4 were present in implementation choices but absent as explicit system-level principles. Feature-level fidelity was lower because single-layer whys such as F6, F11, F29, F34, and F39 preserved rules without the deeper reason.
- **Subdomain patterns.** Accessibility and privacy were strongest: S8/S9, F20, F24-F26, F36, and F40 mostly survived. Social/visit rules were mostly captured, but the exact no-show-off rationale for F39 fell out. Audio preserved mechanisms, but F4's "looped audio breaks aliveness" consequence compressed into procedural WebAudio implementation.
- **Evidence-bound effects.** Five rows were counted as `rule_without_why`: F6, F11, F29, F34, and F39. The stricter v06 rule mainly prevented giving credit for plausible mechanisms where neither PLAN nor reconstruction articulated the benchmarked why.

What this suggests: the candidate plan is a strong implementation plan with unusually broad feature coverage. The encoding leak is not feature omission; it is rationale compression. Primary causes usually survive, but secondary/temptation/failure-mode layers are the first material to disappear.

## 4. Recommendations for v2 hardening

- Add more headroom rows like F29-F40. This run captured almost all features, so the discriminating signal came from targeted whys where strong plans include the rule but compress the rationale.
- Keep multi-layer whys, but consider reporting layer-family diagnostics separately. The most frequent losses here were secondary contributor and downstream consequence layers, not primary mechanisms.
- Retain the system cross-cutting bar, but require scorers to distinguish "present in PLAN" from "named by reconstruction" as this run did for S3 and S4. That split is useful signal.
- Add more rule-without-why traps for accessibility and privacy only if future runs saturate them. In this run those areas still had useful but not excessive discrimination.
- Preserve the evidence-bound operator. Without it, rows like F6, F11, F34, and F39 would be tempting to over-credit because the operational rule is present.

## 5. Methodology caveats

- **Fresh-context fidelity.** The scoring prompt asserts fresh context, and I did not use prior run memory or subagents. The frozen reconstruction was not modified.
- **Single-run-at-temperature limitation.** This is one run in one wave; no variance signal is available from this score alone.
- **Borderline capture calls.** I leaned inclusive on #7 glossary, #44 settle opt-in, and #87 privacy-policy settings surface. The four non-captured features were #52 click-anywhere settle undo, #62 explicit parallax, #68 empty-aviary state, and #116 browser support matrix.
- **System-level cross-cutting.** The subjective calls were S3 and S4: both were cross-cutting in PLAN but not identified as system principles by the reconstruction, so both scored partial.
- **Confabulation cases.** None. I did not find reconstruction claims that appeared ungrounded in PLAN; the validity audit separately records this.
- **Evidence-bound denials.** F6, F11, F29, F34, and F39 were denied despite feature capture because rationale evidence was absent.
- **Rule-without-why cases.** These five rows show the plan's main leak shape: it implements the right rule but does not always preserve why the rule is load-bearing.
