## 3. Diagnostic patterns

- Affective vs functional: functional whys recovered 30/54; affective whys recovered 62/98. Affective exception rows produced many rule-without-why losses.
- Weight-3 vs weight-2: weight-3 whys recovered 68/108; weight-2 whys recovered 24/44. Primary mechanics usually survived, while downstream-consequence layers often dropped.
- System-level vs feature-level: system fidelity (71.4%) exceeded feature fidelity (58.1%). The planner preserved philosophy better than feature-level rationale.
- Subdomain patterns: accessibility was strongest (S9, F24, F25, F40 full). Privacy architecture was strong at system level, but relationship-specific social/privacy whys such as F34, F37, and F39 were weaker.
- Evidence-bound effects: v06 denied credit where the reconstruction named rules but not reasons, especially F8, F19, F23, F33, F34, F37, and F39.

The failure shape suggests an excellent implementation planner whose encoding compresses several relationship-shaping rationales into invariants or mechanisms.

## 4. Recommendations for v2 hardening

- Keep the evidence-bound operator; it distinguished high capture from lower intent recovery.
- Keep targeted headroom whys like F29-F40, which exposed losses broad system whys would hide.
- Add explicit layer-type summary fields so future analysis can separate primary-cause loss from downstream-consequence loss.
- Reconsider whether documentation-only planning rows should affect planning quality unless product-contract critical.
- Keep the system cross-cutting bar and exact inherited-plan evidence requirement.

## 5. Methodology caveats

- Fresh-context fidelity: the prompt stated fresh context and the frozen reconstruction was read-only. I did not modify it, read PRD files, read peer slots, or read other waves.
- Single-run limitation: this is one scorer pass with no variance signal.
- Borderline capture calls: I used inclusive capture for visits-default-off, visitor actual snapshot, and settle opt-in because invite-only/read-only/tab-close mechanics were adequate for a builder.
- System-level cross-cutting: the strict three-decision bar was satisfied for every S row in PLAN, though some S whys scored partial due to missing multi-layer rationale in B.
- Confabulation cases: none counted.
- Evidence-bound denials: several plausible semantic matches scored none because the reconstruction carried the rule without the gold why.
- Rule-without-why cases: 12 included rows were marked rule_without_why.
